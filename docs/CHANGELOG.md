# Changelog

RSVP follows a content-versioning policy. Version numbers track changes to the documented content: measures, definitions, reporting rules and pages. Copy edits and layout changes do not bump the version.

## Versioning Policy

| **Bump** | **When** | **Example** |
|---|---|---|
| MAJOR | A measure is renamed or removed, or a reporting rule changes so that old reports are not comparable | The visibility rate is redefined |
| MINOR | A new measure, a new guide page or a new report format | A new measure page is added |
| PATCH | A substantive section added to an existing page | A new section on edge cases |

A change that alters a definition or a rule raises the minor number. A wording or correction change does not, and it is recorded under the same version with its date.
